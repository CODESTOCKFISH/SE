## Problem Statement

**Pharmacy Expiry & Re-order Dispatch Engine**

The project models a pharmacy inventory system that manages medicine batches,
identifies expired medicines, follows FEFO (First Expired, First Out) dispensing,
and automatically generates stock re-order requests when inventory falls below
the required threshold.

---

## Lab Objective

This lab demonstrates the use of **Jira for Agile/Scrum project management**,
including:

- Creating an Epic and associated User Stories
- Assigning Story Points
- Organizing work into Sprints
- Managing the Product Backlog
- Running an Active Sprint
- Tracking work through workflow states
- Completing Sprint work
- Analysing the Sprint Burndown Chart
- Performing Sprint reflection and analysis
